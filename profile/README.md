# Noillirk.net

**Think like everyone. Climb with the crowd.**

[Play Noillirk Daily](https://noillirk.net/) · [Learn the rules](https://noillirk.net/how-to-play.html) · [See how scoring works](https://noillirk.net/scoring.html)

Noillirk is a daily crowd-guessing game: answer ten prompts, with 30 seconds for each one, and try to pick the answer most people would give. At [Noillirk.net](https://noillirk.net/), you can start playing, learn the rules in a minute, and explore a detailed guide with real gameplay screenshots and practice ideas.

- **New to the game?** [Read the quick how-to-play guide](https://noillirk.net/how-to-play.html).
- **Want to improve your score?** [Explore the scoring bands and calculator](https://noillirk.net/scoring.html).
- **Ready to go deeper?** [Read the complete Noillirk guide](https://noillirk.net/guide.html).
